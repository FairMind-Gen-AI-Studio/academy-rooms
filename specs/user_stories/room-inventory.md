As an administrator, I want to maintain a list of rooms with details such as room name, capacity, and equipment so that users can easily find and book suitable rooms for their events or meetings.

**Acceptance Criteria:**
1. The system should have a dedicated 'Room Management' section in the admin panel.
2. I should be able to add new rooms with unique room names, capacities, and equipment lists.
3. The system should validate that room names are unique.
4. I should be able to edit or update existing room details.
5. I should be able to delete rooms that are no longer in use.
6. The system should display a list of all rooms with filter and search options based on room name, capacity, and equipment.
7. The room list should be updated in real-time as changes are made.

**Additional Considerations:**
- Consider adding a 'Room Groups' feature for mass room management.
- Implement a room status (e.g., available, under maintenance) to help with room booking.
- Allow users to submit requests for new equipment in a room.
