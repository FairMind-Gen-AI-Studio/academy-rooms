# User Story 4: Dark Mode Theme
As a user, I want to toggle between light and dark mode themes so that I can comfortably use the application in different lighting conditions and reduce eye strain.

**Acceptance Criteria:**
1. The system should provide a visible toggle button to switch between light and dark modes.
2. The theme preference should persist across sessions using local storage.
3. The system should respect the user's system-level theme preference by default.
4. All UI elements, including text, backgrounds, and interactive components, should adapt appropriately to the selected theme.
5. The theme switch should be smooth and not cause any visual disruptions or layout shifts.

**Additional Considerations:**
- Implement proper color contrast ratios for accessibility in both themes.
- Consider adding an auto-switch feature based on time of day.
- Ensure all charts, calendars, and status indicators remain clearly visible in both themes.
- Test the themes thoroughly across all pages and components to maintain consistency.
